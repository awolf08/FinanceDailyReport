# 2026-09-17 美股盘前分析

## 9/17 美股盘前

昨天 Fed 加息 25bp，把利率提高到 **3.75%–4.00%**，同时点阵图仍暗示今年可能还有一次加息。昨天市场先杀估值，尤其 Dow 明显走弱。今天盘前出现反弹，主要原因不是 Fed 转鸽，而是 **10Y 美债收益率重新跌破 5%、油价回落，市场在做超跌修复。**

盘前指数期货整体明显反弹：**ES 约 +1.2%～1.3%，NQ 约 +1.6%，YM 约 +1.2%**，科技股暂时最强。10 年国债收益率回到约 **4.97%–4.99%**，这是今天风险资产反弹最重要的支持。

今天早上的初请失业金人数降到 **19.6 万**，低于市场预期的约 20.7 万，说明就业市场暂时仍然比较稳。这个数字本身偏经济强，但目前市场更关注的是债券端没有继续失控。

另一个利好是 **油价回落**。Brent 从本周高位明显下跌，目前仍在 $100 上方，但油价下降暂时缓解了通胀和长端收益率继续冲高的压力。

## 今天交易重点

### 1. 先看 10Y 能不能守在 5% 以下

如果重新突破 5%，今天这个 gap-up 很容易被卖；如果能稳定在 4.95% 附近甚至继续下降，科技股反弹更容易延续。

### 2. NQ / QQQ 今天明显强于 DIA

昨天市场杀的是利率敏感资产，今天收益率回落后，资金首先回来买科技。因此短线看，NQ 的弹性比 YM / DIA 更好。

### 3. 不要把今天盘前上涨直接理解成新一轮主升

Fed 刚刚开始加息，而且还留下继续加息的空间。目前更像是连续下跌之后的 relief rally。真正重要的是今天开盘后能不能守住第一轮回踩。

### 4. DIA 仍然值得关注

DIA 已经从 52 周高点回调约 6%，明显比 SPX / NDX 弱。如果收益率后面继续回落，Dow 有补涨机会；但如果 10Y 再冲 5%，工业、金融和高负债板块仍会承压。

## 我的盘前判断

今天基准情景是：

**高开 → 第一小时震荡 / 回踩 → 决定反弹是否能延续**

我不会在盘前 +1% 以上的位置追多，反而更关注开盘后的第一次回踩。如果 ES / NQ 回踩不破关键支撑，同时 10Y 继续 <5%，可以考虑做日内反弹；如果高开以后迅速失守 opening range，同时收益率反弹，则要防范 gap fill。

今天最大的两个指标不是新闻，而是：

**10Y Treasury：5%**  
**Oil：是否继续回落**

只要这两个没有重新恶化，今天空头会比较被动。

## Bottom Line

今天盘前最值得盯的是一个很清楚的组合：**NQ 强 + 10Y 跌破 5% + 油价下降**。这也是为什么今天先定义成“反弹日候选”，但还不能直接定义成趋势翻转。
